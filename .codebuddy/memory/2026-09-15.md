### 顺手修复的既有缺陷（notify 生成通知的 run 脚本）
bash 解析 `python3 -c '...'` 时，**python 代码块内出现单引号会提前终止 bash 字符串** → 整段 python 不执行、
`notice.md`/`notice.html` 不生成 → notify step 必失败。命中两处：
1. `'<html><body style="font-family:...sans-serif;' 'font-size:...">\n'`（拼 HTML）
2. `r'<a href="\2">\1</a>'`（Markdown 链接转 HTML）

修法：改用双引号 + 转义 —— `"<html>...\"..."`、`"<a href=\"\\2\">\\1</a>"`。
⚠️ **不能**图省事写成 r-string（`r"...\"..."` 会把反斜杠原样保留，HTML 里多出 `\`）。

### 校验方式（本机可复用）
- YAML 结构：`python3 -c "import yaml; yaml.safe_load(open(f))"`（本机 pyyaml 6.0.1 可用）
- 内嵌 shell：把 `${{ ... }}` 替换为占位后 `bash -n`
- notify 实跑：提取该 step 的 `run` 到临时文件，注入
  `TAG/REPO/GH_TOKEN/BUILD_RESULT/BUILD_JC_RESULT/INDEX_RESULT/GITHUB_STEP_SUMMARY` 后执行，检查 `notice.md/notice.html`
  → 实测 `rc=0`，JoyCode tag 场景标题为「发布通知 · JoyCode Linux 包发布成功 ✅」
- check-joycode.sh：`bash -n` + `DRY_RUN=1 JOYCODE_EXE_URL=... bash check-joycode.sh`（实测 tag 计算 `joycode-v3.0.11-1` 正确）
