## 发布完成通知接入（build-deb.yml 新增 notify job）
- 需求：构建成功/发布新版后能推送到企微机器人、微信等。
- 落地：`build-deb.yml` 末尾新增 `notify` job（`needs: [build, update-index]`，`if: always() && tag`），两个 step：
  1. 用 GITHUB_TOKEN 拉 Release 资产 → python 生成 `notice.md`（Markdown，含版本/时间 UTC+8/下载直链，构建失败则标 ❌）与 `notice.txt`，并写入 `$GITHUB_STEP_SUMMARY`。
  2. 单 step 内按 secret 是否存在依次发送，未配置即跳过并计数：企微群机器人(WECOM_WEBHOOK, msgtype=markdown)、PushPlus(PUSHPLUS_TOKEN)、Server酱(SERVERCHAN_KEY)、Telegram(TG_BOT_TOKEN+TG_CHAT_ID)、ntfy(NTFY_TOPIC)、Bark(BARK_URL)。
- 已本地演练：YAML 合法（jobs=build/update-index/notify）；无 secret 时输出「未配置任何通知通道」优雅退出。
- 注意：企微群机器人若设「自定义关键词」，默认填「发布通知」（通知标题已含该词）；不要开 IP 白名单（GH runner IP 不固定）。密钥一律走 Secrets（公有仓库，日志自动 mask）。
- 微信侧结论：官方不开放个人号机器人；「推到微信」只能走服务号中转（Server酱/PushPlus/WxPusher）或企微应用消息+微信插件。零代码方案：Watch → Custom → Releases（邮件）、`releases.atom` 喂 RSS。

## 追加：邮件通道
- 需求：发布信息推送到邮箱。
- 落地：生成 step 增加 `notice.html`（极简 md→html：h2/引用灰字/链接/ul）；发送 step 增加通道 7「邮件」，用 Python 标准库 `smtplib` 直发（不用第三方 action），multipart/alternative（纯文本 + HTML），主题 `TITLE · TAG`。
- 邮件 Secrets：`MAIL_SMTP_HOST` / `MAIL_SMTP_PORT`(465 默认 SSL，其它走 STARTTLS，starttls 失败时降级明文) / `MAIL_USERNAME` / `MAIL_PASSWORD`(授权码) / `MAIL_TO`(逗号或分号分隔) / `MAIL_FROM`(可选)。
- 已用一个假 SMTP 服务器端到端演练：rc=0、`multipart/alternative`、text/plain+text/html、多收件人、deb 直链均在；SMTP 不可达时打印「邮件发送失败」且不计数（失败路径正确）。

## 通知配置位置 / GitHub 账号邮件结论
- 全部通知通道密钥的配置位置：GitHub 仓库 Settings → Secrets and variables → Actions（Repository secrets）
  `https://github.com/testerxydw/github-release-pkg-url/settings/secrets/actions`（需 admin；新增后下次运行生效；名称必须与 workflow 中 `secrets.XXX` 完全一致，写错只会静默跳过）。
- 本仓库 secrets 清单：既有 `PRIVATE_REPO_PAT`、`WB_X_USER_ID`；通知相关 `WECOM_WEBHOOK`、`PUSHPLUS_TOKEN`、`SERVERCHAN_KEY`、`TG_BOT_TOKEN`、`TG_CHAT_ID`、`NTFY_TOPIC`、`BARK_URL`、`MAIL_SMTP_HOST`、`MAIL_SMTP_PORT`、`MAIL_USERNAME`、`MAIL_PASSWORD`、`MAIL_TO`、`MAIL_FROM`。
- 结论：workflow **无法**用 GitHub 账号邮箱发信（GitHub 不提供发信 API）。想收「GitHub 账号邮件」只能靠订阅机制：
  ① 仓库 Watch → Custom → Releases（仅成功发布 Release 时触发，邮件内容为 GitHub 模板、不可定制、无失败告警）；
  ② Settings → Notifications → Actions（失败 workflow 邮件）；
  ③ `releases.atom` 交给 RSS→邮件服务（Blogtrottr/Feedrabbit）转发，零 SMTP。
