## 变更一（上午）：补丁版/原味版版本号统一为同一版本号，用包名区分 —— 当日即被变更二取代

**需求**：构建出的补丁版（`5.9.0-1`）与无补丁版（`5.9.0-2-nopatch`）版本号不一致，要求两者一致（都 `5.9.0-1`），用包名区分。

**根因**：CI `build-deb.yml` 的 build job 连续跑两次 `build.sh`（先 `--patch` 后 `--no-patch`）；
`stage_deb` 读 control 的 Version 并按 exe 主版本自增 revision → 第二次变 `-2`；CI 再 `mv` 追加 `-nopatch` 后缀。
两包安装路径相同（`/opt/workbuddy`），实际会互相覆盖（原注释宣称的"可共存"并不成立）。

**当时做法**（已随仓库还原全部回退，仅留档）：
- build.sh 引入 `PKG_VARIANT`/`PKG_NAME`/`OPT_BASE`/`APP_NAME` 变体机制；`DO_PATCH=0` 时版本号沿用 control 值；
  清理整个 `deb-pkg/opt`；desktop/bin/图标/postinst 全按变体命名并清理另一变体残留。
- build-deb.yml：第二步不再改名；发布 glob 改 `com.xydw.workbuddy*_<arch>.deb`；NAME_MAP 加 `workbuddy-nopatch`。
- 顺带修了一个既有 bug：图标残留清理 `find -name 'workbuddy.png'` 从未生效（实际文件名 `com.xydw.workbuddy.png`）。
- 验证通过：两包 Version 均 `5.9.0-1`、Package 不同、文件清单无冲突。

## 变更二（当日，最终方案）：彻底放弃补丁版，只出原味版单包

**背景**：两个仓库都被 `git checkout` 还原到远程版，变更一的改动**全部回退**。
用户新决策：不需要打前端补丁了，不需要补丁版，**默认就是无补丁版，且只保留一个版本**，包名用
`com.xydw.workbuddy_5.9.0-1_amd64.deb` 这种标准形式。

### 最终改动（在远程版基础上的最小改动）

**build.sh**（私有仓库 `testerxydw/workbuddy-linux` · `win-to-linux` 分支，本地 `/home/ub24/文档/script/traework-linux/workbuddy-linux/build.sh`）
——只改 3 处注释/默认值，**未引入任何包名后缀机制**：
1. `DO_PATCH=1` → `DO_PATCH=0`（默认不再打前端补丁，只出原味版）
2. usage 增加 `--patch` 说明行（标明默认已关闭）
3. `stage_patch_app` 头部注释补一句"默认不执行，仅 --patch 显式开启"
- 保留：`--patch` / `--no-patch` 开关、`stage_patch_app` 函数、主流程 `if [[ DO_PATCH -eq 1 ]]` 守卫（作对比用）。
- 产物命名/安装路径天然标准（远程版从未加过后缀）：`com.xydw.workbuddy_<版本>_<架构>.deb`、`/opt/workbuddy`、`workbuddy`。
- **版本号逻辑一律未动**（远程版原样）：exe 主版本变化归 1、同版本 revision+1。
  ⚠️ 特别警惕：别把变更一"原味版沿用 control 版本号"的分支再加回来——那只在双包场景成立，
  单包场景会导致版本号永不递增、产物同名覆盖。

**build-deb.yml**（本仓库，唯一被改文件，`git status` 可见 `M .github/workflows/build-deb.yml`）：
- 删除「构建 deb（补丁版）」step；原「构建 deb（原味版 --no-patch）」改为「构建 deb（原味版）」，
  调用为 `bash build.sh --arch ${{ matrix.arch }} --no-install`（不传 patch 参数，靠 build.sh 新默认）；
  去掉 `/tmp/deb-patched` 暂存与 `-nopatch` 改名。
- 发布 glob 保持 `src/com.xydw.workbuddy_*_${{ matrix.debarch }}.deb`（原本就匹配，无需改）。
- 头部注释 + step 注释更新为"每版每架构只出一个原味包"，并留历史沿革说明。
- `update-index` / `NAME_MAP` 无需改动（不再产生 `workbuddy-nopatch` 资产）；历史索引条目保留不改。
